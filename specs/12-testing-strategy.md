# Testing Strategy

## Scope
Unit, integration, and schema tests.

## Tasks
- Unit tests for ADTs and validation.
- Integration tests with mocked Canvas API.
- Golden tests for JSON output schemas.
- CLI help snapshot tests.

## Acceptance Criteria
- Tests cover edge parsing and invalid input paths.
- JSON output tests guard against breaking changes.

## Notes
- Keep mocks aligned with Canvas API v1 responses.
