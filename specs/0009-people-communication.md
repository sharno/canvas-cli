# People and Communication

## Scope
User lists and outbound communication.

## Tasks
- Implement `user list` (students, TAs, teachers).
- Implement message/announcement send.
- Manage groups if enabled.

## Acceptance Criteria
- Filters for roles are supported.
- Messages require explicit subject/body fields.
- JSON output includes recipient counts and IDs.

## Notes
- Avoid sending messages without `--confirm`.
